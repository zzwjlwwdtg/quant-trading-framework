📖 术语说明 / 缩写字典（点开）
NAV (Net Asset Value)
账户净值。现金 + 持仓市值。例：$1,130,000
DD (Drawdown 回撤)
从历史 Peak 跌了多少%。DD -30% = 从最高点掉了 30%。-30% = 100万 → 70万
Peak
账户历史最高 NAV。用来算 DD 基准。
RSI (Relative Strength Index)
相对强弱指标，0-100。<30 超卖（可能反弹）| 30-70 正常 | >70 超买（可能回调）
CCI (Commodity Channel Index)
顺势指标，衡量偏离均值程度。-100 到 +100 正常 | <-100 超卖 | >+100 超买
MA20 / MA50
20日 / 50日移动均线。价格站上 MA20 = 短期偏多。
共振多空条 (bull vs bear)
9+ 维技术指标投票（RSI/MA/CCI/量/BB/PSAR 等）。多3 vs 空1 = 3 个指标看多，1 个看空
Regime (市场状态)
系统对当前交易环境的日线判断，不等同于 HMM 慢周期背景。neutral 中性 · neutral_chop 中性震荡 · crisis 危机 · overheated 过热
HMM Meta-Regime
Hidden Markov Model 判定的 SPY 慢周期背景。它用于风险背景，不是当前买入或加仓信号。长期偏多也可能同时处于短线震荡偏弱
Confidence (置信度) X/5
系统对信号的把握程度。5 分制（TECHNICAL_ONLY 模式）。1/5=弱 · 3/5=中 · 5/5=强
WATCH_BUY / WATCH_BUY_PROBE / BUY / REDUCE / SELL / CAUTION / HOLD
建议动作：WATCH_BUY 关注买入 · WATCH_BUY_PROBE 主动试探仓 · BUY 买入 · REDUCE 减仓 · SELL 卖出 · CAUTION 警示不加仓 · HOLD 观望
Pyramid Layer (加仓层)
金字塔加仓的第几层。L1=初始，L2=第一次加，L3=第二次加。最多 3 层。
Entry Price (入场价)
本笔仓位的第一次买入价，用于算浮盈 + 移动止损基准。
Options Risk (期权风险等级)
基于三巫日临近程度 + gamma 拥挤度。low 平稳 · medium 关注 · high 高波动
三巫日 (Triple Witching)
每季 3/6/9/12 月第三个周五，期指+期权+股指期权同时到期，波动放大。
Gold Macro (黄金宏观)
实际利率+美元指数+Fed 资产负债表+原油 4 因子综合，判定黄金方向。bullish +2 = 温和看涨
Trump Signal
Trump Truth Social 24h 推文 CLI 解析，仅作参考不进决策（TECHNICAL_ONLY 模式）。
DRY / LIVE
DRY = 只写日志不下单（dry-run 测试）· LIVE = 在 moomoo SIMULATE 账户真实下单
OpenD
moomoo 官方开放交易接口服务，本地运行在 127.0.0.1:11111。挂了 → 系统拿不到实时报价 + 无法下单。
Orchestrator
主调度进程。跑在后台，每天 5 个 ET 窗口（08:30/09:20/10:00/12:00/15:45）自动跑决策 + 下单。
